## ⚡ Key Simulation Features

* **Authentic 150-Question Blueprint:**
  * **Part I: Language (Qualifying):** Q1 to Q30 (Minimum 30% / 9 marks qualifying requirement).
  * **Part II: General Studies:** Q31 to Q70 (40 Marks counted towards final merit).
  * **Part III: Computer Science:** Q71 to Q150 (80 Marks core technical domain).
* **Strict Evaluation Scheme:** +1.0 Mark for correct answers, **-0.333 (1/3rd penalty)** for incorrect answers.
* **Persistent Pause & Resume:** Safe timer and response preservation during pauses.
* **Integrated Google Drive Sync:** Direct cloud backup to `BPSC_TRE_My_Attempts` folder.
* **Granular Solutions & Analytics:** Full Question Palette review, topic diagnostics, and time-pace analytics.
